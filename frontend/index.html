🔒 Privacy Architecture

How this system protects user data using state-of-the-art privacy-preserving techniques.

🌐
Federated Learning
User data never leaves the local device. Each client trains locally on their own history and only model gradient updates are shared with the server. Orchestrated via Flower (flwr) with FedAvg aggregation.
flwr 1.x · FedAvg
🔐
Differential Privacy
Gaussian noise is injected into model updates before transmission (DP-SGD). Gradient clipping bounds sensitivity, ensuring individual user behaviour cannot be inferred from the aggregated model even with adversarial access.
DP-SGD · Gaussian Noise
🛡️
Secure Aggregation
Masked secure aggregation prevents the server from observing any individual client's raw gradient. Only the sum of masked updates is revealed, providing cryptographic privacy guarantees on top of DP.
SecAgg · Masking Protocol
🧠
Multimodal Privacy
Pre-extracted embeddings (DistilBERT + ResNet-18) are cached server-side. Clients receive only embedding lookups — raw text and images never travel over the network, reducing information leakage at the modality level.
DistilBERT · ResNet-18
📊
No Performance Trade-off
Our federated model with DP achieves AUC 0.980 vs centralized AUC 0.975 — privacy comes at zero cost to recommendation quality. This is enabled by the embedding-cache design and attentive user encoder.
AUC 0.980 · nDCG 0.980
📋
MIND Dataset
Trained on the Microsoft News Dataset (MIND), a large-scale benchmark for news recommendation with 160K+ users and 65K+ articles across 20 categories spanning politics, sports, tech, lifestyle and more.
MIND · 65K+ Articles
